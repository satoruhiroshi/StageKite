StageKite is a decentralized, event-driven platform utilizing a distributed provisioning and load balancing as a scalable processing framework.

With StageKite, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/StageKite.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
